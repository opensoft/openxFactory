# Avatar Reference Runtime Acceptance Traceability

Status: draft
Kind: register
Captured: 2026-07-10
Proposed by: implement-avatar-reference-runtime

[`avatar-reference-runtime-acceptance-map.yaml`](avatar-reference-runtime-acceptance-map.yaml)
owns eight `ARR-*` requirements and 34 scenarios. The deterministic suite also
maps every applicable contract-kernel `ACR-*` scenario to a test or explicit
non-applicability disposition. Final evidence must use the exact released
kernel and canonical fixtures with the provisional adapter disabled.

F0 and UI evidence remain sibling-owned and cannot complete runtime tasks.
