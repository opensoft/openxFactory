## Seam defect found and fixed on the way

The inline scout (`real_invoke`) failed "Not logged in" on this
profile-scoped workstation: the `_scrubbed_env` keep-list drops
`CLAUDE_CONFIG_DIR`, the pointer to the CLI's login (set by profile-scoped
workstations). Like `HOME` it locates credentials rather than being one.
Fixed identically in the four sibling seams (`neutrality_dispatch`,
`semantic`, `ideation_readiness`, `derive_possibles`); doc-health suite 609
passed. CI is unaffected either way (it authenticates via
`ANTHROPIC_API_KEY`, which the scrub already keeps). The audit and fixture
runs above went through the REAL fixed seam, not a harness substitute.
