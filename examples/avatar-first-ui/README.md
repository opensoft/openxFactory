# Avatar-First UI Examples

These examples show how domain factories specialize the shared
openxFactory avatar-first UI template.

The examples are static contract examples. They are not runtime state and do
not contain secrets, customer records, transcripts, or generated workspaces.

Files:

- [domain-overlays.example.yaml](domain-overlays.example.yaml) shows Medx,
  opencodex, Opsx, and Ledgerx overlays using the same avatar-first template.
