# Proposal: annotated draft

The SYMMETRY case. An annotated `draft` declares `draft` for exactly the same
reason an annotated `ratified` declares `ratified` — one leading-token reader,
applied in both directions. A rule that read annotations only when they made a
packet louder would be two rules wearing one name.
