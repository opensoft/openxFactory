# Existing CLI compatibility boundary

The public script path and every current flag/precedence remain unchanged.
Provider calls preserve current command ordering, profile binding and failure
semantics. The wrapper retains directly consumed helper names and patchable
provider, timing and dashboard seams. No runtime dependency or contract release
is introduced. The lifecycle projection remains the policy owner.

Upload reconciliation preserves identity-keyed polling, post-ingestion rename
verification, content-matched adoption and duplicate prevention. Discovery,
record updates, hosting resolution and session host registration preserve main.
The scoped quality command fails on every configured checker finding and on a
missing required checker. Both supported test discovery modes remain hermetic.
